## 🧠 Featured Project — Viora AI

**Viora AI** is a complete AI assistant that runs entirely on your device. No cloud. No subscriptions. No data leaving your machine.

| Feature | Description |
|---|---|
| 💬 Chat | Local LLM (Qwen 0.6B GGUF) with real-time streaming |
| 🎤 Voice Input | Whisper & Vosk — online and fully offline modes |
| 🗣 Voice Output | Piper TTS with natural, low-latency speech |
| 👁 Vision | USB/Pi Camera + Hailo object detection |
| ✅ Agent | Task scheduler — set reminders and recurring jobs |
| 🌦 Weather | Open-Meteo (no API key needed) |
| 🗺️ Maps | Organic Maps — fully offline navigation |
| 🤖 Dev AI | Built-in coding assistant via OpenCode |

> Built with Python · React · FastAPI · Electron
